## Summary

Two modules with no database access: period arithmetic from the global anchor, and the contract's scoring formula as a pure `Decimal` function, pinned by golden vectors. Everything that scores — nightly and at period close — calls these and nothing else for the math.

This story has **no database dependency** and can be written first, in parallel with the FOUNDATION chain (see 00-INDEX.md "Suggested ordering change"). It is also the scoring formula, the highest-consequence code in the phase.

## Background

### What exists today (current architecture)

- Nothing in `app/elevate/` computes. Flags are read via `app.core.flags.flag(tenant_id, name, default)` (`backend/app/core/flags.py:53`), TTL-cached 60 s.
- The contract formula (page 3): `allowed = miles/1000 × allowed_rate`; `excess = max(0, count − allowed)`; `penalty = excess × weight`; `score = clamp(100 − Σ penalties, 0, 100)`; below minimum exposure → "Not enough driving data". Example: 1,000 mi, five High (w5), allowance 3 → 90.
- `programme_versions.rules` (FOUNDATION-2) = `[{vendor_id, vendor_event_ref, severity_label, weight, allowed_per_1000mi, dedup_group}]`.

### What this story does (the proposed change)

Creates `backend/app/elevate/periods.py`, `backend/app/elevate/scoring.py` and `backend/app/elevate/shapes.py` (the one module holding every Elevate JSONB shape), and their tests. No I/O.

### Why we're making this change (per the decision log)

D4: anchor `2026-01-05T00:00:00Z`, flag `elevate.periods.anchor`. D13 (amended 16 Sep 2026, Codex finding 1): *"one count per incident per group, under the highest-weighted **matched** rule"* — the count is keyed by that rule, and the penalty uses **that rule's** weight and allowance. A group has no weight or allowance of its own; it only prevents double counting.

"""Every Elevate JSONB column's shape, once."""
from __future__ import annotations
from datetime import date, datetime
from decimal import Decimal
from typing import Annotated, Literal
from pydantic import BaseModel, ConfigDict, StringConstraints, TypeAdapter

class Strict(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

RuleKey = Annotated[str, StringConstraints(pattern=r"^[^:]+:.+$")]

RuleCounts = dict[RuleKey, int]
PenaltyMap = dict[RuleKey, Decimal]
RULE_COUNTS = TypeAdapter(RuleCounts)
PENALTY_MAP = TypeAdapter(PenaltyMap)

class RuleMaps(Strict):
    rule_counts: RuleCounts
    penalties: PenaltyMap

class FrozenRule(Strict):                    # elevate_programme_versions.rules[i]
    vendor_id: str
    vendor_event_ref: str
    severity_label: Literal["low", "medium", "high", "critical"]
    weight: Decimal
    allowed_per_1000mi: Decimal
    dedup_group: str
FROZEN_RULES = TypeAdapter(list[FrozenRule])

class RuleRef(Strict):                       # elevate_session_evidence.rules_fired[i]
    vendor_id: str
    vendor_event_ref: str
    category: str
RULES_FIRED = TypeAdapter(list[RuleRef])

class ScoreSnapshotV1(Strict):               # elevate_sessions.score_snapshot

    period_end: date

    score: Decimal
    threshold: Decimal
    min_exposure_miles: Decimal
    rule_counts: RuleCounts
    penalties: PenaltyMap
    excluded_count: int
    config_version: int
    scoring_version: str
