# Visual direction

The September 6 cobalt cosmetic pass is retired. The governing baseline is [Elevate Autocoach — Design Library v1.1](../Elevate-Autocoach-Design-Library.md), dated September 7, 2026, with the product integration rules in [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md).

Use Ember orange for actions and location, petrol for neutral data, ink for headline values, and independent semantic families for status and directional change. Apply the library's complete native controls, typography, shared KPI/table/chart anatomy, and accessibility states—not a color-only overlay.

The older `visual-refresh*.png`, driver/session screenshots, and `session-redesign.html` are historical artifacts. They do not authorize blue tokens, brand-colored charts, font downloads, gradients, colored conversation bubbles, or old component states. Current validation is recorded in [design-library migration](design-library-migration.md).
